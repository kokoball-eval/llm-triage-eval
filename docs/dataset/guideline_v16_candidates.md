# 판정 기준서 v1.6 변경 후보

판정 기준서([`triage_guideline.md`](triage_guideline.md))는 현재 v1.5이고, v1.5 평가셋 라벨·재채점·회귀 게이트의 기준이다. 진행 중인 버전의 기준을 바꾸면 이미 낸 결과와 기준이 어긋나므로, 새로 생긴 규칙은 이 목록에 모았다가 v1.6 기준서를 만들 때 한꺼번에 검토한다. 각 후보는 v1.6 검토에서 라벨 영향 문항을 확인한 뒤 반영 여부를 정한다.

| 번호 | 후보 | 들어갈 곳 | 제안 | 근거 |
| :---: | :--- | :--- | :--- | :--- |
| V16-1 | **크로스 플랫폼 재현 확인** — 크로스 플랫폼 게임(PC·모바일 동시 서비스)에서 한 플랫폼에서만 재현·제보된 이슈는 다른 플랫폼에서도 재현을 시도해야 한다(모바일 → PC, PC → 모바일 모두). 재현 범위가 영향 범위와 우선순위 판단을 바꾸기 때문이다 | §5 재현 정보, `[누락 정보 및 권장 조치]` | 검토자 (2026-10-29) | QA 실무 — 플랫폼 공통 코드의 결함은 한쪽 제보만으로 범위를 판단하면 영향 범위를 작게 잡는다 |

## v1.6 검토 때 확인할 것

- **V16-1** — 플랫폼을 하나만 적은 제보·이슈 문항에서 `[누락 정보 및 권장 조치]` 정답에 다른 플랫폼 재현 시도를 넣을지, 모델 출력에 그 권장이 없을 때 감점할지. 이 칸은 지금 자동 채점 대상이 아니므로 먼저 채점 방식을 정한다.
