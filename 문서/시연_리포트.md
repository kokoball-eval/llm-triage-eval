# 시연용 예시 리포트

휴대폰 시연(`uv run triage-serve --lan`)에서 **내 업무 → + 새 리포트 넣기**에 붙여 넣어 볼 예시입니다. 가상 게임 "Aether Raid"의 리포트이며 모두 이 문서를 위해 새로 쓴 글입니다(평가셋과 무관).

사용법: 서버를 켠 뒤([README 휴대폰으로 시연하기](../README.md)) [내 업무]의 [+ 새 리포트 넣기]를 펼쳐 입력 종류를 고르고, 아래 제목·본문을 붙여 넣은 뒤 `추가 정보`에 게시판·작성자를 넣고 [트리아지]를 누릅니다. 모델이 채운 8칸을 확인하고 [BTS 등록]까지 눌러 보세요. 모델 답은 매번 조금씩 달라질 수 있어, 아래 "볼 것"은 기대하는 방향입니다.

| # | 입력 종류 | 모델이 낸 판정(2026-11-26 실제 모델) | 보여 주려는 것 |
| :-: | :--- | :--- | :--- |
| 1 | A · 커뮤니티 제보 | 결함 · 결제·재화 · Critical · 긴급 사인 요청 | **긴급 사인 요청**은 QA팀장이 받고, 팀장이 [사인 후 개발 전달]을 눌러야 개발팀에 넘어감 |
| 2 | A · 커뮤니티 제보 | 버그 아님 · UI·텍스트 · Trivial · CS 응대 | 모델이 놓친 것을 사람이 고치는 시연 — [분류]를 결함, [처리]를 개발 배정으로 고치면 개발팀에 배정되고 목표 스프린트가 우선순위(Trivial)에 따라 3주 뒤로 잡힘. 대시보드의 사람 수정 비율에 반영 |
| 3 | A · 커뮤니티 제보 | 버그 아님 · 판단보류 · 등록(재현 대기) | 정보가 부족한 제보를 모델이 확정하지 않고 판단보류로 남김 |
| 4 | A · 커뮤니티 제보 | 문의·건의 · 계정·로그인 · CS 응대 | 문의 글은 CS 응대로 분류(QA 재현이 필요 없으면 BTS에서 Check 상태) |
| 5 | B · QA 이슈 | 결함 · 클라이언트 안정성 · Critical · 긴급 사인 요청 | 재현 정보가 충분한 QA 이슈. 크래시라 1번처럼 팀장 사인으로 감 |
| 6 | A · 커뮤니티 제보 | 결함 · 게임플레이·밸런스 · Major · 등록(재현 대기) | QA팀에 배정되어 **QA Review**, [재현 확인]을 누르면 개발팀 구성원에게 넘어감 |

모델 답은 실행마다 조금 달라질 수 있습니다. 위 판정이 아니어도 8칸을 검토 화면에서 고치면서 진행하면 됩니다.

시연 순서 제안: 1번 → 2번(사람이 고침) → 6번을 등록하고 **홈**에서 [지금 동기화] → QA Review 표에서 담당자와 할 일 확인 → **내 업무**의 [재현 확인하기]·[사인하기]로 개발에 넘기기 → BTS에서 Resolve로 바꾼 뒤 [회귀 테스트 결과 넣기]까지 눌러 보면 한 바퀴가 돕니다. 마지막에 **대시보드**에서 병목·부하를, **트리아지 품질**에서 사람 수정 비율을 봅니다. 실제 BTS에 이슈가 생기므로 시연 뒤에 정리합니다.

---

## 1. 결제했는데 다이아가 안 들어와요

* 입력 종류: A · 커뮤니티 제보 / 게시판: `공식 홈페이지 > 버그 제보`
* 제목: `다이아 패키지 결제했는데 다이아가 안 들어와요 (결제는 빠져나감)`

```
어제 저녁 9시쯤 모바일(안드로이드)에서 다이아 1,200개 패키지를 결제했습니다.
카드 승인 문자도 왔고 구글 플레이 결제 내역에도 나오는데, 게임 안 우편함과 보유 다이아는 그대로예요.
앱을 껐다 켜도, 로그아웃했다가 다시 들어가도 똑같습니다.
영수증 번호는 GPA.3321-0000-0000-00000 입니다. 빠른 확인 부탁드립니다.
```

## 2. 도감의 오타

* 입력 종류: A · 커뮤니티 제보 / 게시판: `공식 홈페이지 > 버그 제보`
* 제목: `도감에서 소환수가 소환스로 표시돼요`

```
도감 > 소환수 탭 맨 위 제목이 "소환스 도감"으로 적혀 있어요.
다른 화면에서는 "소환수"로 잘 나오는데 도감 탭만 그렇습니다. 게임 하는 데는 지장 없고 그냥 오타 같아서 알려요.
```

## 3. 정보가 부족한 제보

* 입력 종류: A · 커뮤니티 제보 / 게시판: `자유게시판`
* 제목: `게임이 자꾸 이상해요`

```
요즘 게임이 자꾸 이상하게 됩니다. 어제도 그랬고 오늘도 그랬어요. 고쳐 주세요.
```

## 4. 계정 이전 문의

* 입력 종류: A · 커뮤니티 제보 / 게시판: `건의게시판`
* 제목: `폰을 바꿨는데 계정을 어떻게 옮기나요?`

```
새 휴대폰으로 바꿨는데 기존 계정을 그대로 쓰고 싶어요.
어디서 계정 연동이나 이전을 하는지 모르겠습니다. 방법 좀 알려 주세요.
```

## 5. 월드 보스 입장 시 멈춤 (QA 이슈)

* 입력 종류: B · QA 이슈 / 작성자: `내부 QA`
* 제목: `월드 보스 입장 시 로딩 100%에서 멈추고 강제 종료`

```
[환경] 안드로이드 13, 빌드 0.9.3(2041), 와이파이
[재현 절차]
1. 레벨 30 이상 캐릭터로 월드 보스 "공허의 군주" 입장 버튼 터치
2. 로딩 바가 100%에서 멈춤 (약 20초)
3. 앱이 응답 없음 후 강제 종료
[재현율] 10회 중 6회
[기대 결과] 보스 전투 화면 진입
[실제 결과] 로딩 100%에서 멈춘 뒤 강제 종료. 같은 빌드의 iOS 에서는 10회 모두 정상
[첨부] 로그 파일 2개
```

## 6. 아레나 지형 악용 공략

* 입력 종류: A · 커뮤니티 제보 / 게시판: `공략게시판`
* 제목: `아레나 3번 맵 왼쪽 바위 뒤에 서면 아무도 못 때립니다`

```
아레나 3번 맵(폐허 도시)에서 왼쪽 큰 바위와 벽 사이 틈에 끼어서 스킬을 쓰면 상대 원거리 공격이 전부 바위에 막혀요.
저는 이걸로 어제 랭킹전 12연승 했습니다. 상대는 저를 때릴 수가 없고 저는 스킬이 나가요.
같은 길드원 3명도 해 봤는데 똑같이 됩니다. 공략으로 올리니 참고하세요.
```
